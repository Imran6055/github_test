# WSL File System Architecture

This documentation explains how Windows Subsystem for Linux (WSL) stores, exposes, and interoperates with Linux filesystem. WSL has two different architectures, and the storage mechanism is different for each. Understanding WSL storage means understanding the difference between WSL1 vs WSL2.
