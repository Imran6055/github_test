# WSLg Filesystems

WSLg enables Linux GUI applications to run natively on Windows without a separate X server or VM


## Special mounts:
* `/mnt/wsl`
* `/mnt/wslg`
* `/run/WSL`


## Include Compenents 

* Wayland socket
* X11 socket
* PulseAudio
* shared memory (VirIO-Based)

We will see more about Wslg in a separate section.
