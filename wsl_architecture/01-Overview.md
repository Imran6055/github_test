
# Overview

WSL (Windows Subsystem for Linux) is a Windows feature that allows execution of Linux binaries directly inside Windows — without a traditional VM in WSL 1, and using a lightweight VM running a real Linux kernel in WSL 2.

WSL acts as a Linux environment broker built on top of the Windows NT kernel. How it works depends on whether you're using WSL 1 or WSL 2.
